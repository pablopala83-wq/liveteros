# V3.9.13 · Staff sync and match identity fix

- Local match cache is isolated by authenticated user.
- Online match list no longer silently falls back to another user's legacy cache.
- Successful online loads refresh the current user's offline cache from canonical match rows.
- Match tagging saves no longer write opponent_name/opponent_color, so tagging cannot revert a later match edit.
- Match edit RPC synchronizes opponent name/color into live_state identity keys for compatibility.
- Existing live_state identity values were reconciled to matches.opponent_name/opponent_color.
