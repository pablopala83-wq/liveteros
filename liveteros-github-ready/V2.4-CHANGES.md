# Live Teros V2.4 · Brand Kit

## Imagen
- Aplicación del Brand Kit Los Teros v1.0 a login, gestión de partidos, tagging y dashboard.
- Colores: Navy 950 `#031738`, Navy 800 `#08294A`, Celeste `#00A9E0`, Blanco `#F7FAFC`, Positivo `#2ED17D`, Negativo `#F05B66`.
- Ámbar reservado para estados pendientes / revisión.
- Fallback digital del manual: Arial Black para títulos y Arial para texto. No se incluyen archivos de fuentes.
- Radios digitales de 12 px, grilla basada en 8 px y superficies más sobrias.
- Escudo reducido a uso interior estable, sin marca de agua.
- Zonas dejan de usar rojo/verde para evitar mezclar geografía con semántica de resultado.
- Botones principales conservan targets táctiles grandes, especialmente en iPad horizontal.

## Juego con el pie
- Se elimina `PELOTA MUERTA` del resolver de kicks.
- Se reemplaza por `DEAD IN-GOAL`, que cierra la secuencia sin crear posesión rival.
- Drop fallado que termina muerto se registra como `DEAD IN-GOAL`.
