# V3.8 · EDICIÓN DE ETIQUETAS

- La lista de acciones LITE ahora muestra botones **EDITAR** y **×** en cada fila.
- **×** elimina la etiqueta real y actualiza las estructuras vinculadas (Line/Scrum, quiebres, penales, score y entradas a 22 cuando corresponde).
- **EDITAR** permite corregir los campos de Line, Scrum, Quiebre y Penal; en scores/entradas permite corregir el equipo.
- Las etiquetas nuevas llevan un identificador estable para enlazar la fila visible con el dato real.
- Las inferencias automáticas de Entrada a 22 quedan vinculadas con la acción que las originó, para que una corrección no deje datos huérfanos.
- La lista LITE conserva hasta 60 acciones y todas quedan accesibles mediante scroll.
- Se mantiene DESHACER como capa adicional de seguridad.
