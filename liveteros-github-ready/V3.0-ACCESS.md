# Live Teros V3.0 - Accesos

## Modelo
- Cada partido tiene un unico etiquetador asignado.
- Solo el etiquetador asignado puede modificar el estado del partido.
- Los administradores pueden cambiar el etiquetador desde ACCESO.
- Los entrenadores/viewers no necesitan cuenta: usan un link de solo lectura del partido.
- Generar un nuevo link invalida el anterior.
- El link puede desactivarse en cualquier momento.

## Flujo recomendado
1. El admin crea el partido. Queda asignado como etiquetador por defecto.
2. Si etiqueta Ruma, ACCESO -> ETIQUETADOR ASIGNADO -> ingresar su email.
3. Ruma necesita una cuenta en Live Teros una sola vez.
4. ACCESO -> DASHBOARD SOLO LECTURA -> GENERAR / RENOVAR LINK.
5. Compartir ese link con Guzman, Caco y staff.
6. Los viewers abren directamente el dashboard sin login.
