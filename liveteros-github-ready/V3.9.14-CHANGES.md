# V3.9.14

- Staff access no longer uses individual users/passwords in the frontend.
- One shared staff link gives access to all matches and full tagging/editing.
- Shared staff access is protected by a separate app token carried in a request header, not by exposing Supabase secret/service credentials.
- Existing Auth users are preserved in the backend only as rollback/fallback.
- Match assignment is ignored in shared staff mode: all staff-link users can tag any match.
- Match list, creation, editing and deletion work through shared staff access.
- Active match updates use polling in shared-link mode so the custom staff token remains enforced.
- Per-match coach/dashboard read-only links remain available from COMPARTIR.
