# V3.9.4 - Discipline timeline

- Adds a chronological penalty timeline inside the Discipline dashboard card.
- Penalties committed by URU are shown in red; opponent penalties in green.
- Consecutive URU penalties are grouped and labelled as streaks (2 SEGUIDOS, 3 SEGUIDOS, etc.).
- Shows the maximum URU penalty streak.
- Opponent penalty groups show how many URU penalties came immediately before them.
- No tagging, storage, penalty logic, or other dashboard sections changed.
