# Live Teros V3.1

- Dashboard LINE dividido en dos columnas: ATAQUE URU a la izquierda y DEFENSA a la derecha.
- Cada columna mantiene lista completa y porcentaje de obtención por cantidad real de jugadores en el line.
- Si se asigna como etiquetador un email que todavía no existe, Live Teros crea la cuenta automáticamente y envía un Magic Link de acceso.
- Se agregó ingreso por Magic Link para etiquetadores ya creados, sin necesidad de contraseña.
- Viewers por link continúan sin cuenta y en modo sólo lectura.
- Cache actualizado a V3.1.
