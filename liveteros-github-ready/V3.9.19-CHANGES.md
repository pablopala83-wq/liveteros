# V3.9.19 · SCRUM RESET

- Adds RESET to Scrum result options in LITE and FULL.
- RESET is a technical restart, not a rugby result.
- RESET does not create a launch, does not count in obtention percentages and does not appear in the Scrum dashboard list.
- In FULL, tapping SCRUM while an event-free Scrum sequence is open offers RESET directly; RESET removes that open Scrum and starts the next Scrum flow immediately.
- RESET is undoable as an atomic action when closing an already-open Scrum.
- PENAL / FREE KICK / obtention behavior is unchanged.
